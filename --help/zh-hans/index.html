开放数据 · 所有平台

所有游戏的地图，覆盖所有平台。

纯 JSON · 无需账号与密钥 · 每日更新

Atlas 从一个商店到另一个商店绘制游戏地图：哪些广为人知，哪些本周被阅读最多，哪些即将推出，哪些彼此相似。简单的 JSON 文件，免费使用，每天重新绘制。

平台

一张地图，一个平台接一个平台

每个平台都有自己的文件夹，文件格式相同。游戏在各商店的 ID 将平台连接在一起。

  • Nintendo Switch

    即将推出

    来自维基百科的知名度与趋势，来自 Wikidata 的系列与工作室，相似游戏和版本。

  • Steam

    即将推出

    来自维基百科和 Steam 评测的知名度、最多人玩的游戏、标签和相似游戏。

  • GOG

    即将推出

    完整的 GOG 目录，含评测。

  • Xbox and Microsoft Store

    即将推出

    Microsoft Store 的游戏、玩家评分和 Game Pass 中的游戏。

  • Nintendo 3DS

    即将推出

    各地区的 3DS 游戏及其 title id，来自 Nlib API 和 Wikidata。

  • PlayStation 4

    即将推出

    来自 Wikidata 的 PS4 游戏：发售日期、特征和 PlayStation Store id（索尼的条款禁止收集商店的数据）。

  • PlayStation 5

    即将推出

    来自 Wikidata 的 PS5 游戏：发售日期、特征和 PlayStation Store id（索尼的条款禁止收集商店的数据）。

  • Retro

    即将推出

    已无任何商店出售的游戏，来自 Wikidata。

文件

发布了什么，何时发布

每个文件、它的大小和生成日期。超过两天的每日文件或超过九天的每周文件会标记为延迟。

文件内容生成大小更新
index.json每个文件的日期、大小和哈希每周——

每个文件都有架构编号：可能会新增字段，旧字段的含义保持不变。 各来源和平台的新鲜度

使用

无需账户，无需密钥，没有限制

文件是普通的 JSON。从任何方便的地方读取。

  • 通过 jsDelivr

    数据分支，由快速 CDN 提供。地址永不改变。

    https://cdn.jsdelivr.net/gh/JigSawFr/Atlas@data/platforms/switch/popular.json

  • 从本站

    同样的文件，位于 data/ 下，每次运行重新生成。

    https://atlas.boreale.dev/data/platforms/steam/popular.json

  • 只取变化的部分

    index.json 给出每个文件的哈希：每天获取一次，然后只下载有变化的文件。

    {"files": {"platforms/switch/popular.json": {"generated": "2026-11-02", "bytes": 71646, "sha256": "11c54e3b7c6f150f"}}}

  • 每周发布

    每个周一的文件都会作为发布永久保存，每个文件都附有证明。最新版本始终在同一地址。

    https://github.com/JigSawFr/Atlas/releases/latest/download/switch-popular.json
gh attestation verify switch-popular.json -R JigSawFr/Atlas

每个文件的格式（逐字段）见 README

来源

数据来自哪里

只使用无需账户的来源。每个文件都注明了自己的来源。

  • Wikidata游戏、系列、工作室、类型、评论、各商店的 IDCC0
  • Wikimedia每款游戏页面被阅读的次数，八种语言CC0
  • titledbSwitch 游戏及其介绍和发售日期按原样发布
  • SteamSteam 游戏、评测、标签和最多人玩的游戏Steam Web API 条款
  • SteamSpySteam 游戏的拥有者和玩家按原样发布
  • IGDB主题、关键词和玩家评分（设置了其密钥时）IGDB API 条款

密钥

无需密钥

没有密钥一切照常运行。两个可选密钥可增加一些信息，作为仓库的机密设置。

  • IGDB_CLIENT_IDIGDB_CLIENT_SECRETIGDB，通过 Twitch 应用：主题、关键词、玩家评分和期待度。
  • STEAM_API_KEYSteam 应用的完整列表，超出 Wikidata 已知的游戏。
