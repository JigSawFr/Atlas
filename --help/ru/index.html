Открытые данные · все платформы

Карта всех игр на всех платформах.

Простой JSON · Без аккаунта и ключа · Обновляется каждый день

Atlas наносит видеоигры на карту от магазина к магазину: какие известны, о каких больше всего читают на этой неделе, какие скоро выйдут и какие похожи. Простые файлы JSON, свободные для использования, перерисовываются каждый день.

Платформы

Одна карта, платформа за платформой

У каждой платформы своя папка, файлы в одних и тех же форматах. Идентификаторы игры в каждом магазине связывают платформы.

  • Nintendo Switch

    Скоро

    Известность и тренды по Википедии, серии и студии по Wikidata, похожие игры и издания.

  • Steam

    Скоро

    Известность по Википедии и отзывам Steam, самые популярные, метки и похожие игры.

  • GOG

    Скоро

    Весь каталог GOG с отзывами.

  • Xbox and Microsoft Store

    Скоро

    Игры Microsoft Store, оценки игроков и то, что есть в Game Pass.

  • Nintendo 3DS

    Скоро

    Игры 3DS всех регионов с их title id по данным Nlib API и Wikidata.

  • PlayStation 4

    Скоро

    Игры PS4 по данным Wikidata: даты выхода, характеристики и id PlayStation Store (условия Sony запрещают собирать данные магазина).

  • PlayStation 5

    Скоро

    Игры PS5 по данным Wikidata: даты выхода, характеристики и id PlayStation Store (условия Sony запрещают собирать данные магазина).

  • Retro

    Скоро

    Игры, которые уже не продаёт ни один магазин, по Wikidata.

Файлы

Что публикуется и когда

Каждый файл, его размер и день создания. Ежедневный файл старше двух дней или еженедельный старше девяти помечается как запоздавший.

ФайлЧто в нёмСоздаётсяРазмерОбновлён
index.jsonКаждый файл с датой, размером и хешемкаждую неделю——

У каждого файла есть номер схемы: могут появиться новые поля, старое сохраняет своё значение. Насколько свежи источники и платформы

Использование

Без аккаунта, без ключа, без лимитов

Файлы — простой JSON. Читайте их откуда удобно.

  • Через jsDelivr

    Ветка данных через быстрый CDN. Адрес никогда не меняется.

    https://cdn.jsdelivr.net/gh/JigSawFr/Atlas@data/platforms/switch/popular.json

  • С этого сайта

    Те же файлы в data/, обновляются при каждом запуске.

    https://atlas.boreale.dev/data/platforms/steam/popular.json

  • Только изменения

    index.json содержит хеш каждого файла: запрашивайте его раз в день и скачивайте только изменившиеся файлы.

    {"files": {"platforms/switch/popular.json": {"generated": "2026-11-02", "bytes": 71646, "sha256": "11c54e3b7c6f150f"}}}

  • Еженедельные релизы

    Файлы каждого понедельника навсегда сохраняются в релизе, каждый с аттестацией. Последний всегда по одному адресу.

    https://github.com/JigSawFr/Atlas/releases/latest/download/switch-popular.json
gh attestation verify switch-popular.json -R JigSawFr/Atlas

Формат каждого файла, поле за полем, описан в README

Источники

Откуда это

Только источники, не требующие аккаунта. Каждый файл называет свои.

  • WikidataИгры, серии, студии, жанры, критика, идентификаторы в каждом магазинеCC0
  • WikimediaКак часто читают страницы каждой игры, на восьми языкахCC0
  • titledbИгры Switch, их описания и даты выходакак опубликовано
  • SteamИгры Steam, отзывы, метки и самые популярныеУсловия Steam Web API
  • SteamSpyВладельцы и игроки игр Steamкак опубликовано
  • IGDBТемы, ключевые слова и оценки игроков, если заданы его ключиУсловия API IGDB

Ключи

Не нужны

Всё работает без ключа. Два необязательных добавляют немного данных и хранятся как секреты репозитория.

  • IGDB_CLIENT_IDIGDB_CLIENT_SECRETIGDB через приложение Twitch: темы, ключевые слова, оценки игроков и ожидания.
  • STEAM_API_KEYПолный список приложений Steam, помимо игр, известных Wikidata.
