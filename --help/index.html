Platforms

One map, platform after platform

Each platform has a folder of its own, its files in the same formats. A game's ids on every store tie the platforms together.

  • Nintendo Switch

    Coming

    Renown and trends from Wikipedia, series and studios from Wikidata, games alike and editions.

  • Steam

    Coming

    Renown from Wikipedia and Steam's reviews, the most played, tags and games alike.

  • GOG

    Coming

    The whole GOG catalogue with its reviews.

  • Xbox and Microsoft Store

    Coming

    The Microsoft Store's games, their players' ratings and what is in Game Pass.

  • Nintendo 3DS

    Coming

    The 3DS's games across their regions, with their title ids, from Nlib API and Wikidata.

  • PlayStation 4

    Coming

    The PS4's games from Wikidata: release dates, traits and PlayStation Store ids (Sony's terms forbid collecting the store's data).

  • PlayStation 5

    Coming

    The PS5's games from Wikidata: release dates, traits and PlayStation Store ids (Sony's terms forbid collecting the store's data).

  • Retro

    Coming

    The games no store sells any more, from Wikidata.

Use it

No account, no key, no limit

The files are plain JSON. Read them from wherever suits you.

  • From jsDelivr

    The data branch, served by a fast CDN. The address never changes.

    https://cdn.jsdelivr.net/gh/JigSawFr/Atlas@data/platforms/switch/popular.json

  • From this site

    The same files, under data/, made again with each run.

    https://atlas.boreale.dev/data/platforms/steam/popular.json

  • Only what changed

    index.json gives each file's hash: ask for it once a day, then fetch only the files that changed.

    {"files": {"platforms/switch/popular.json": {"generated": "2026-11-02", "bytes": 71646, "sha256": "11c54e3b7c6f150f"}}}

  • Weekly releases

    Every Monday's files are kept for good as a release, each file attested. The latest is always at the same address.

    https://github.com/JigSawFr/Atlas/releases/latest/download/switch-popular.json
gh attestation verify switch-popular.json -R JigSawFr/Atlas

Each file's format, field by field, is in the README

Sources

Where it comes from

Only sources that need no account. Each file names its own.

  • WikidataGames, series, studios, genres, critics, ids on every storeCC0
  • WikimediaHow often each game's pages are read, in eight languagesCC0
  • titledbThe Switch's games, their descriptions and release datesas published
  • SteamSteam's games, reviews, tags and most playedSteam Web API terms
  • SteamSpyOwners and players of Steam gamesas published
  • IGDBThemes, keywords and players' ratings, when its keys are setIGDB's API terms

Keys

None needed

Everything works without a key. Two optional ones add a little, set as the repository's secrets.

  • IGDB_CLIENT_IDIGDB_CLIENT_SECRETIGDB, through a Twitch application: themes, keywords, players' ratings and hype.
  • STEAM_API_KEYSteam's full list of apps, beyond the games Wikidata knows.
