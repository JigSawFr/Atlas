オープンデータ · すべてのプラットフォーム

すべてのゲームの地図を、すべてのプラットフォームで。

シンプルなJSON · アカウントもキーも不要 · 毎日更新

Atlas はストアからストアへゲームを地図にします。有名なゲーム、今週よく読まれているゲーム、もうすぐ出るゲーム、似ているゲーム。シンプルな JSON ファイルで、自由に使え、毎日描き直されます。

プラットフォーム

ひとつの地図を、プラットフォームごとに

プラットフォームごとにフォルダーがあり、ファイルは同じ形式です。各ストアでのゲームの ID がプラットフォーム同士をつなぎます。

  • Nintendo Switch

    近日対応

    Wikipedia からの知名度とトレンド、Wikidata からのシリーズとスタジオ、似ているゲーム、エディション。

  • Steam

    近日対応

    Wikipedia と Steam のレビューからの知名度、最もプレイされたゲーム、タグ、似ているゲーム。

  • GOG

    近日対応

    GOG の全カタログを、レビューつきで。

  • Xbox and Microsoft Store

    近日対応

    Microsoft Store のゲーム、プレイヤーの評価、Game Pass の内容。

  • Nintendo 3DS

    近日対応

    全地域の3DSソフトとそのタイトルID（Nlib APIとWikidataより）。

  • PlayStation 4

    近日対応

    WikidataによるPS4のゲーム：発売日、特徴、PlayStation StoreのID（ソニーの規約はストアのデータ収集を禁じています）。

  • PlayStation 5

    近日対応

    WikidataによるPS5のゲーム：発売日、特徴、PlayStation StoreのID（ソニーの規約はストアのデータ収集を禁じています）。

  • Retro

    近日対応

    どのストアでも売られていないゲームを Wikidata から。

ファイル

何が、いつ公開されるか

各ファイル、そのサイズと作成日。2 日より古い毎日のファイルや、9 日より古い毎週のファイルには遅延の印がつきます。

ファイル内容作成サイズ更新
index.json各ファイルの日付、サイズ、ハッシュ毎週——

各ファイルにはスキーマ番号があります。新しいフィールドが加わることはあっても、既存のフィールドの意味は変わりません。 各ソースとプラットフォームの鮮度

使い方

アカウントもキーも制限もなし

ファイルはただの JSON です。好きな場所から読めます。

  • jsDelivr から

    データブランチを高速な CDN で配信。アドレスは変わりません。

    https://cdn.jsdelivr.net/gh/JigSawFr/Atlas@data/platforms/switch/popular.json

  • このサイトから

    同じファイルを data/ に。実行のたびに作り直されます。

    https://atlas.boreale.dev/data/platforms/steam/popular.json

  • 変わったものだけ

    index.json は各ファイルのハッシュを示します。1 日 1 回取得し、変わったファイルだけをダウンロードしてください。

    {"files": {"platforms/switch/popular.json": {"generated": "2026-11-02", "bytes": 71646, "sha256": "11c54e3b7c6f150f"}}}

  • 毎週のリリース

    毎週月曜日のファイルはリリースとしてずっと保管され、各ファイルに証明がつきます。最新版はいつも同じアドレスです。

    https://github.com/JigSawFr/Atlas/releases/latest/download/switch-popular.json
gh attestation verify switch-popular.json -R JigSawFr/Atlas

各ファイルの形式はフィールドごとに次で説明しています： README

ソース

データの出どころ

アカウントのいらないソースだけを使っています。各ファイルに自分のソースが書かれています。

  • Wikidataゲーム、シリーズ、スタジオ、ジャンル、批評、各ストアでの IDCC0
  • Wikimedia各ゲームのページが読まれた回数、8 言語分CC0
  • titledbSwitch のゲーム、その説明と発売日公開されているとおり
  • SteamSteam のゲーム、レビュー、タグ、最もプレイされたゲームSteam Web API の規約
  • SteamSpySteam のゲームの所有者数とプレイヤー数公開されているとおり
  • IGDBテーマ、キーワード、プレイヤー評価（キーが設定されている場合）IGDB API の規約

キー

キーは不要

キーがなくてもすべて動きます。任意の 2 つのキーを、リポジトリーのシークレットとして設定すると少し情報が増えます。

  • IGDB_CLIENT_IDIGDB_CLIENT_SECRETIGDB（Twitch アプリケーション経由）：テーマ、キーワード、プレイヤー評価、期待度。
  • STEAM_API_KEYWikidata が知るゲーム以外も含む、Steam のアプリの完全な一覧。

ゲームごとに道を見つけよう

エクスプローラーは同じファイルを読みます。ゲームを探し、各プラットフォームの情報を見て、似ているゲームを見つけましょう。
