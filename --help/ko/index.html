Atlas는 스토어에서 스토어로 게임을 지도에 담습니다. 잘 알려진 게임, 이번 주 많이 읽힌 게임, 곧 나올 게임, 비슷한 게임. 단순한 JSON 파일로 자유롭게 쓸 수 있고 매일 새로 그립니다.

플랫폼

하나의 지도, 플랫폼마다

플랫폼마다 폴더가 있고 파일 형식은 같습니다. 각 스토어에서의 게임 ID가 플랫폼을 서로 잇습니다.

  • Nintendo Switch

    예정

    Wikipedia의 인지도와 트렌드, Wikidata의 시리즈와 스튜디오, 비슷한 게임, 에디션.

  • Steam

    예정

    Wikipedia와 Steam 리뷰의 인지도, 가장 많이 플레이된 게임, 태그, 비슷한 게임.

  • GOG

    예정

    GOG 전체 카탈로그와 리뷰.

  • Xbox and Microsoft Store

    예정

    Microsoft Store 게임, 플레이어 평점, Game Pass 목록.

  • Nintendo 3DS

    예정

    모든 지역의 3DS 게임과 타이틀 ID(Nlib API와 Wikidata 기준).

  • PlayStation 4

    예정

    Wikidata 기준 PS4 게임: 출시일, 특징, PlayStation Store ID(소니 약관은 스토어 데이터 수집을 금지합니다).

  • PlayStation 5

    예정

    Wikidata 기준 PS5 게임: 출시일, 특징, PlayStation Store ID(소니 약관은 스토어 데이터 수집을 금지합니다).

  • Retro

    예정

    더 이상 어느 스토어에서도 팔지 않는 게임, Wikidata에서.

파일

무엇이 언제 공개되는지

각 파일과 크기, 만든 날짜. 이틀이 지난 일간 파일이나 9일이 지난 주간 파일은 지연으로 표시됩니다.

파일내용생성크기업데이트
index.json각 파일의 날짜, 크기, 해시매주——

각 파일에는 스키마 번호가 있습니다. 새 필드가 추가될 수 있지만 기존 필드의 의미는 바뀌지 않습니다. 각 소스와 플랫폼의 최신 상태

사용하기

계정도, 키도, 제한도 없이

파일은 단순한 JSON입니다. 편한 곳에서 읽으세요.

  • jsDelivr에서

    빠른 CDN이 제공하는 데이터 브랜치. 주소는 바뀌지 않습니다.

    https://cdn.jsdelivr.net/gh/JigSawFr/Atlas@data/platforms/switch/popular.json

  • 이 사이트에서

    같은 파일을 data/ 아래에, 실행할 때마다 새로 만듭니다.

    https://atlas.boreale.dev/data/platforms/steam/popular.json

  • 바뀐 것만

    index.json은 각 파일의 해시를 알려 줍니다. 하루 한 번 받아 바뀐 파일만 내려받으세요.

    {"files": {"platforms/switch/popular.json": {"generated": "2026-11-02", "bytes": 71646, "sha256": "11c54e3b7c6f150f"}}}

  • 주간 릴리스

    매주 월요일 파일은 릴리스로 영구 보관되며 파일마다 증명이 붙습니다. 최신 릴리스는 늘 같은 주소에 있습니다.

    https://github.com/JigSawFr/Atlas/releases/latest/download/switch-popular.json
gh attestation verify switch-popular.json -R JigSawFr/Atlas

각 파일의 형식은 필드별로 다음에 있습니다: README

출처

데이터의 출처

계정이 필요 없는 출처만 씁니다. 각 파일에 자신의 출처가 적혀 있습니다.

  • Wikidata게임, 시리즈, 스튜디오, 장르, 평론, 각 스토어 IDCC0
  • Wikimedia각 게임 문서가 읽힌 횟수, 8개 언어CC0
  • titledbSwitch 게임과 설명, 출시일공개된 그대로
  • SteamSteam 게임, 리뷰, 태그, 가장 많이 플레이된 게임Steam Web API 약관
  • SteamSpySteam 게임의 소유자와 플레이어공개된 그대로
  • IGDB테마, 키워드, 플레이어 평점(키가 설정된 경우)IGDB API 약관

키

필요 없음

키 없이도 모두 작동합니다. 선택 키 두 개를 저장소 시크릿으로 설정하면 정보가 조금 늘어납니다.

  • IGDB_CLIENT_IDIGDB_CLIENT_SECRETTwitch 애플리케이션을 통한 IGDB: 테마, 키워드, 플레이어 평점, 기대도.
  • STEAM_API_KEYWikidata가 아는 게임 너머의 Steam 앱 전체 목록.

게임별로 길을 찾으세요

탐색기는 같은 파일을 읽습니다. 게임을 찾고, 플랫폼마다 무엇을 말하는지 보고, 비슷한 게임을 찾아보세요.
