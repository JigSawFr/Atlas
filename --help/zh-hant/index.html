平台

一張地圖，一個平台接一個平台

每個平台都有自己的資料夾，檔案格式相同。遊戲在各商店的 ID 把平台連在一起。

  • Nintendo Switch

    即將推出

    來自維基百科的知名度與趨勢，來自 Wikidata 的系列與工作室，相似遊戲與版本。

  • Steam

    即將推出

    來自維基百科與 Steam 評論的知名度、最多人玩的遊戲、標籤與相似遊戲。

  • GOG

    即將推出

    完整的 GOG 目錄，含評論。

  • Xbox and Microsoft Store

    即將推出

    Microsoft Store 的遊戲、玩家評分與 Game Pass 中的遊戲。

  • Nintendo 3DS

    即將推出

    各地區的 3DS 遊戲及其 title id，來自 Nlib API 和 Wikidata。

  • PlayStation 4

    即將推出

    來自 Wikidata 的 PS4 遊戲：發售日期、特徵和 PlayStation Store id（索尼的條款禁止收集商店的資料）。

  • PlayStation 5

    即將推出

    來自 Wikidata 的 PS5 遊戲：發售日期、特徵和 PlayStation Store id（索尼的條款禁止收集商店的資料）。

  • Retro

    即將推出

    已無任何商店販售的遊戲，來自 Wikidata。

檔案

發佈了什麼，何時發佈

每個檔案、它的大小與產生日期。超過兩天的每日檔案或超過九天的每週檔案會標示為延遲。

檔案內容產生大小更新
index.json每個檔案的日期、大小與雜湊每週——

每個檔案都有結構編號：可能會新增欄位，舊欄位的意義保持不變。 各來源與平台的新鮮度

使用

無需帳號，無需金鑰，沒有限制

檔案是一般的 JSON。從任何方便的地方讀取。

  • 透過 jsDelivr

    資料分支，由快速 CDN 提供。網址永不改變。

    https://cdn.jsdelivr.net/gh/JigSawFr/Atlas@data/platforms/switch/popular.json

  • 從本站

    同樣的檔案，位於 data/ 下，每次執行重新產生。

    https://atlas.boreale.dev/data/platforms/steam/popular.json

  • 只取有變化的部分

    index.json 提供每個檔案的雜湊：每天取得一次，然後只下載有變化的檔案。

    {"files": {"platforms/switch/popular.json": {"generated": "2026-11-02", "bytes": 71646, "sha256": "11c54e3b7c6f150f"}}}

  • 每週發佈

    每個週一的檔案都會作為發佈永久保存，每個檔案都附有證明。最新版本永遠在同一網址。

    https://github.com/JigSawFr/Atlas/releases/latest/download/switch-popular.json
gh attestation verify switch-popular.json -R JigSawFr/Atlas

每個檔案的格式（逐欄位）請見 README

來源

資料從哪裡來

只使用無需帳號的來源。每個檔案都註明了自己的來源。

  • Wikidata遊戲、系列、工作室、類型、評論、各商店的 IDCC0
  • Wikimedia每款遊戲頁面被閱讀的次數，八種語言CC0
  • titledbSwitch 遊戲及其介紹與發售日期依原樣發佈
  • SteamSteam 遊戲、評論、標籤與最多人玩的遊戲Steam Web API 條款
  • SteamSpySteam 遊戲的擁有者與玩家依原樣發佈
  • IGDB主題、關鍵字與玩家評分（設定其金鑰時）IGDB API 條款

金鑰

不需要金鑰

沒有金鑰一切照常運作。兩個選用金鑰可增加一些資訊，以儲存庫的機密設定。

  • IGDB_CLIENT_IDIGDB_CLIENT_SECRETIGDB，透過 Twitch 應用程式：主題、關鍵字、玩家評分與期待度。
  • STEAM_API_KEYSteam 應用程式的完整清單，超出 Wikidata 已知的遊戲。
